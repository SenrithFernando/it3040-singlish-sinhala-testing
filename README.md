# IT3040 – Assignment 1  
## Singlish to Sinhala Transliteration Testing

This repository contains automated UI and functional test scripts created using
Playwright to evaluate the Singlish-to-Sinhala transliteration system available at:

https://www.swifttranslator.com/

The purpose of this project is to validate input handling, UI responsiveness,
and robustness of the transliteration system using automated testing techniques.

---

## Tools & Technologies Used

- Playwright
- JavaScript
- Node.js
- Google Chrome (Chromium)

---

## Test Scope

The automated tests cover the following aspects:

- Ability to enter Singlish text into the input field
- UI responsiveness during real-time transliteration
- Stability of the application while processing user input
- Basic UI interaction validation

Note:
The transliteration output is dynamically rendered by the web application and
is not directly accessible through standard DOM selectors. Therefore, the tests
focus on UI behavior and responsiveness rather than exact output text matching.
